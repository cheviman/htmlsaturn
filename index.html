Format: .bin (512 KB). You can also click to open the file picker. It is saved in the browser's DB (Dexie).

Disc

Mounts a Saturn CD image in the drive. In memory only: the disc is not saved in the DB

Drag the game image here

Formats: .cue + .bin (drop the .cue together with all its .bin files at once), or a single .iso / .bin file. You can also click to open the file picker.

The .7z / .zip files have to be extracted first: the emulator has no decompressor. The .chd files are not supported: convert them with chdman extractcd.

Library

Scans a local folder of games (.cue + .bin / .iso) and lists them with their cover (cover.png next to the game). The folder stays saved; each game is loaded into memory only when you pick it

Controls
